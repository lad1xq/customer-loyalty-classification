# Dataset

Download `retail_customer_segmentation.csv` from the original
[Kaggle dataset page](https://www.kaggle.com/datasets/rohit8527kmr7518/online-retail-customer-classification-dataset)
and place it in this directory:

```text
data/retail_customer_segmentation.csv
```

Expected shape: 50,000 rows and 14 columns.

The CSV is intentionally excluded from Git because it is third-party data.
Review the dataset license on Kaggle before redistributing it.
